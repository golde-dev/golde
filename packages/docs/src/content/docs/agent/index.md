---
title: Self-Hosted Agent
description: Run Golde's agent on your own infrastructure.
---

The `golde-agent` binary runs on a host you control and lets Golde manage workloads on that host (Docker containers, static sites, etc.). It installs as a systemd service with an auto-updater.

- **Overview** — what the agent does and when you need it
- **Installation** — one-line install via curl, or manual systemd setup
- **Configuration** — `/etc/golde-agent/.env` and connection settings
- **Upgrading and operations** — managing the running service
