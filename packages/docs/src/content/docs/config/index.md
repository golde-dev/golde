Reference material for the config file itself — separate from the CLI that reads it.

- **File formats** — `.ts`, `.js`, `.cjs`, `.json`, `.yaml`, `.toml`
- **Top-level schema** — the shape of a `golde.config.*`
- **Template variables** — `env`, `git`, `file`, `config`, `state`
- **State backends** — S3, filesystem, Golde Cloud
- **Outputs** — Slack and other notification targets
