Each provider page lists the resource types Golde supports, their config schema, and any provider-specific setup.

| Provider       | Resources                                              |
| -------------- | ------------------------------------------------------ |
| AWS            | S3, Lambda, IAM, Route 53, CloudWatch Logs, App Runner |
| Cloudflare     | DNS, R2, D1                                            |
| GitHub         | Container Registry (GHCR)                              |
| Golde          | Managed Docker containers                              |
| Docker Hub     | Image management                                       |
| Hetzner Cloud  | Servers (schema only)                                  |
