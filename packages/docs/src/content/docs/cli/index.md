The `golde` CLI exposes nine commands.

| Command     | Purpose                                                 |
| ----------- | ------------------------------------------------------- |
| `init`      | Scaffold a new Golde project                            |
| `configure` | Store CLI credentials (Golde API key)                   |
| `validate`  | Check a config without contacting any provider          |
| `show`      | Print the resolved config for the current branch        |
| `plan`      | Generate an execution plan (dry run)                    |
| `apply`     | Apply the plan and update state                         |
| `state`     | Print the current state from the configured backend     |
| `destroy`   | Delete the resources owned by the current branch        |
| `prune`     | Delete resources owned by branches that no longer exist |
